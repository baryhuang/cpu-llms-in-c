Streaming delivery A/B

Decode is an asynchronous submit/wait pair around one in-flight Metal command. While the GPU runs the next forward, the CPU decodes and flushes the newest complete UTF-8 suffix to the descriptor named by QWEN36_STREAM_FD; JSON keeps standard output to itself. Thirteen fresh-process runs in one sitting: one discarded warmup, then four rounds of three variants with the variant order rotated each round. Same images, byte-identical metallib, the 36-token prompt above, greedy seed 42. All 12 measured runs produced identical token IDs and identical text.

Batched prefill A/B

The prompt now runs through compiled S32/S16 batch graphs plus a one-token tail; the final prompt token stays on the logits-producing decode forward. Nine fresh-process runs: one discarded warmup, then four rounds of prefill-on and prefill-off with alternating order, the 36-token prompt above, greedy seed 42. All eight measured runs produced identical token IDs and text.

MetricPrefill offPrefill on

Numeric parity: S16 chunks on the exact kernel path are bitwise identical to the one-token path in all 256 layer-state buffers and probe logits. S32 chunks decide the identical next token in every tested run; their states carry fast-math FMA-contraction drift bounded by 0.0841 absolute on state magnitudes near 20 with zero NaN. End-to-end token parity — the published comparison standard — held on 5/5 smoke prompts and 8/8 A/B runs. Building the batched graph exposed a latent threadgroup race in the decode attention softmax reduction, present but never manifested in the one-token dispatch; both kernels now carry the missing barrier, an ordering-only change.

Optimized kernels and weight residency

Two further measured increments. A tiled simdgroup-matrix GEMM stages a [batch × 64] activation tile and a dequantized [64 × 32] weight tile in threadgroup memory per threadgroup and consumes them with 8×8 simdgroup_multiply_accumulate; the warm S32 chunk drops from 2,035 ms to 864 ms for 32 tokens (2.35x). An MTLResidencySet holding all 644 mapped weight buffers, committed and attached to the command queue at model open, moves Metal first-use wiring out of the first chunk (a parallel CPU prefault had been measured and rejected — the cost is wiring, not page faults). The dual-mode parity test passes: the exact path keeps S16 bitwise identity, the tiled path is argmax-identical with drift bounded by 0.108 and zero NaN; QWEN36_PREFILL_MMA=0 and QWEN36_RESIDENCY=0 restore the previous behavior.
