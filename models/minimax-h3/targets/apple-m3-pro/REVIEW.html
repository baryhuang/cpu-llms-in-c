5. Video VAE optimization

The exact 7×15 256-tile graph has now completed N-to-N: 487.273811 s for Video VAE and 2,418.708237 s total.

The full run recomputed 50 conditioner layers, 200 H3 layer/evaluation calls, 3,780 Video VAE blocks and seven Audio VAE upsampling stages. Packed-image cache hits removed network/import work only. Shell wall was 2,484.38 s because preflight SHA-256 checks are outside the 2,418.708237-second model runtime.

The component command sends deterministic latent data through the real 2.604B-parameter, 36-layer Video VAE. One 256×256×22 task contains 1,797 transformer rows. Verification time is separate from the duration column.

To reproduce the quality-regressed tree experiment, add MINIMAX_H3_TREE_ATTENTION=conservative. Omit it for the default exact-attention path.

The deployed inference binary is compiled without libcurl and does not launch Python, PyTorch, MLX, GGML, llama.cpp, ONNX Runtime or ComfyUI. It uses ffmpeg only for final H.264/AAC output.
