结论： A311Y3 的 1.921 s encoder 仍明显领先。RK3588 专有 FP16 LLMC 的正确 encoder 为 8.725 s（慢 4.5×）；自研 packed-W4 GPU hybrid 把 decoder 降至 4.267 s，但 encoder 仍需 21.717 s，因此端到端为 26.213 s。
新增 RKLLM W8A8： native baseline / LLMC 中位数分别为 12.208 / 12.146 s 端到端，三颗 NPU core 都被观测到；但两者都把同一个逗号 token 重复 128 次，识别失败。官方精度优先 level-1 与 level-0 导出字节完全相同；未修改的 RKLLM 1.3.0 还会在 all-no-RoPE position buffer 上断言，因此这些时间仅是失败路径的执行记录，不是可用成绩。
