# Correctness fixtures

`gemma4_layer_v1.bin` is a deterministic miniature fixture for one early local Gemma 4 text decoder layer.

It contains:

- three input positions;
- an 8-element hidden state;
- two query heads and one KV head;
- 4-element head dimensions;
- a 12-element gated MLP;
- a 4-element per-layer input;
- fixed float32 weights and inputs;
- expected outputs at ten tensor boundaries.

The fixture is generated by `tools/generate_gemma4_layer_fixture.py` using only the Python standard library. The generator implements an independent scalar reference for:

```text
RMSNorm
Q/K/V projection, QK normalization, V normalization, and RoPE
causal sliding-window MQA
attention output normalization and residual
GELU-tanh gated MLP, output normalization, and residual
PLE gate, projection, output normalization, and residual
layer scalar
```

Run:

```sh
make fixture
make test
```

This fixture does not contain official model weights. It does not test global proportional RoPE, shared K/V layers, checkpoint loading, tokenization, final normalization, LM-head evaluation, or decoding.
